# GameLab - 原创小游戏集合

## 🎮 项目简介
GameLab 是一个完全免费的原创小游戏集合网站，融合技术学习和娱乐，所有游戏100%原创开发。

## 🎯 核心特色
- **100%原创游戏**：自主研发游戏机制和美术
- **数字工匠文化**：融入开源、隐私、实用、持续迭代价值观
- **完全免费**：无广告、无内购、无需注册
- **技术学习**：通过游戏学习编程和技术概念
- **响应式设计**：支持PC、手机、平板全平台

## 🛠️ 技术栈
- **游戏引擎**: Phaser.js 3.90.0
- **构建工具**: Vite 7.3.1
- **前端技术**: HTML5, CSS3, JavaScript ES6+
- **部署平台**: Vercel (国际) + Gitee Pages (国内)

## 🎪 游戏规划

### 第一阶段 (规划中)
1. **代码编辑器** - 打字游戏，学习编程语法
2. **开源匠人** - 开源协作模拟游戏
3. **像素艺术家** - 数字绘画和像素艺术创作
4. **二进制冒险** - 二进制学习平台跳跃游戏

### 第二阶段 (待规划)

## 🚀 快速开始

### 开发环境
```bash
# 克隆项目
git clone <repository-url>
cd gamelab

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

### 访问地址
- 开发服务器: http://localhost:3000
- 生产构建: `dist/` 目录

## 🎨 设计理念

### 数字工匠文化植入
- **开源精神**: 游戏代码公开，鼓励学习和改进
- **隐私保护**: 本地游戏，不收集用户数据
- **实用主义**: 游戏兼具娱乐和教育价值
- **持续迭代**: 基于用户反馈不断优化游戏体验

### 视觉风格
- **像素艺术**: 经典复古，加载速度快
- **技术配色**: 蓝色系(代码) + 绿色系(开源) + 橙色系(创造)
- **统一品牌**: 所有游戏保持一致的视觉语言
